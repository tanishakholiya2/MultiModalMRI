Through this project, we are trying to determine whether multi-modal MRI input will improve tumor segmentation accuracy despite applied image degradation. To answer this question, we will use labeled MRI images from the BraTS dataset to train a model that predicts tumor regions in the image. The model produces a pixel-wise classification mask indicating tumor and non-tumor areas.
We will be comparing two distinct input types: single-modality versus multi-modal input. Single-modality input uses only FLAIR MRI scans, a T2-weighted MRI technique that suppresses signals from fluids such as cerebrospinal fluid (CSF). This makes FLAIR particularly useful for highlighting tumor regions and improving the visibility of lesions. (3). Multi-modal input combines T1, T2, and FLAIR MRI sequences in order to provide a more robust representation of tumor regions. The different modalities are aligned and combined so that each pixel contains information from each MRI sequence. Thus, multi-modal MRI images can provide different visuals to highlight different tumor properties (structure, fluid content, etc) (3). 
To simulate real-world imaging conditions, we will introduce controlled degradations to the input images from the BraTS dataset. These degradations will be applied systematically to ensure a fair comparison between single-modality and multi-modal MRI inputs. We will evaluate the robustness of the model across varying conditions, including clean, noisy, and blurred images. Degradations will be introduced using techniques such as Gaussian noise, contrast reduction, and Gaussian blur to simulate different levels of image quality. (5).
